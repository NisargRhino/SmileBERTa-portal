Under the hood

Chemistry, read like language.

SmileBERTa models read a molecule's SMILES string the way a language model reads a sentence. Each string is split into tokens and passed through six transformer layers, which predict a fragment or a therapeutic class.

About

Built to make drug discovery accessible.

SmileBERTa started as a research project on fragment-based drug discovery with chemical language models. It has grown into an open platform where students, researchers and anyone curious can use computational chemistry tools that usually require expensive software and specialised setups.

Built by Nisarg Shah. Questions or collaborations: nisargs2018@gmail.com
