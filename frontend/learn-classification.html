How SmileBERTa classifies drugs

Predicting what a molecule is for from what it is: the data, the model, and the matching step that turns text into a therapeutic class.

The task

Molecules that treat the same kind of disease often share structural features. Statins share a dihydroxy-acid side chain, fluoroquinolones a bicyclic core, and many CNS drugs carry a basic amine. Medicinal chemists use this structure–activity intuition constantly. SmileBERTa's classifier learns it from data: given a SMILES string, it predicts the compound's therapeutic area.

Classification is useful early in discovery for profiling screening hits, spotting repurposing opportunities, flagging likely off-target areas, and annotating large virtual libraries in batch.

Training data

The classifier was trained on 8,336 labelled compounds covering 12 therapeutic categories. About 16% of the compounds (1,350) belong to more than one category. An antibiotic that is also used in oncology, for example, is labelled antiinfective antineoplastic. In total the model can output 38 distinct labels, single categories plus the combinations seen in the data.

The model

The classifier uses the same architecture as the fragment model: a 6-layer RoBERTa encoder initialised from ChemBERTa-zinc-base-v1 (see the architecture section of the fragmentation guide). It is fine-tuned on a different objective. Instead of rewriting the input as a fragment, it writes out the name of the class, token by token, using the same 767-token vocabulary.

Snapping text to a label

Free-form text output is flexible, but it can come out garbled, especially for molecules unlike anything in training. SmileBERTa makes every answer valid by comparing the raw text with each of the 38 known labels using Levenshtein edit distance: the minimum number of single-character insertions, deletions or substitutions needed to turn one string into the other. The closest label wins.

similarity(raw, label) = 1 − levenshtein(raw, label) / max(|raw|, |label|)

Drug-likeness metrics

Next to the class, the tool computes a drug-likeness profile with RDKit:

  • Lipinski's Rule of Five: MW ≤ 500, cLogP ≤ 5, H-bond donors ≤ 5, acceptors ≤ 10. Orally active drugs rarely break more than one of these.
  • Veber rules: rotatable bonds ≤ 10 and TPSA ≤ 140 Å², which correlate with good oral bioavailability.
  • QED (quantitative estimate of drug-likeness): a 0–1 score combining eight properties against the distributions seen in marketed drugs. Above about 0.5 is drug-like.
  • TPSA, Fsp³, aromatic ring count, stereocentres: descriptors chemists use to judge permeability, solubility and synthetic complexity.

Limitations

The classifier learns statistical associations, not mechanisms. It can be confidently wrong. For example, it labels the antibiotic ciprofloxacin as antineoplastic, probably because quinolone-like scaffolds are common in kinase inhibitors. Rare classes (urological, lipid-regulating) are predicted less reliably. Use predictions for prioritisation and hypothesis generation, never as a substitute for biological assays.
