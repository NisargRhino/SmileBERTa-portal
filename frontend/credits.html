Credits & Citations

SmileBERTa is a front end for decades of other people's work. Every tool, model, dataset and published method it uses is listed here with a citation and a licence — so you can check any number the site gives you, and cite the right people when you publish.

If you publish work that used SmileBERTa

Cite the primary sources for whatever you actually used — Vina if you docked, RDKit for descriptors, Delaney for a solubility number — not only this site. SmileBERTa runs those methods; it is not a substitute for them. The sections below say exactly which method produced which result.

You can credit the platform itself as:

Shah, N. SmileBERTa: open, AI-powered drug discovery tools. Emory University, 2026. https://smileberta-web.onrender.com

Each DOI link resolves to a page that will give you BibTeX or RIS for your reference manager.

Licensing

Most of the stack is permissive. Two components are copyleft, and they are called out here rather than buried, because the distinction matters to anyone planning to redistribute this code or build a product on it.

Permissive RDKit, AutoDock Vina 1.2.x, 3Dmol.js, RDKit.js, PyTorch, Transformers, Flask, Werkzeug, Gunicorn, NumPy, pandas, RapidFuzz, Requests, Pillow and Caddy are BSD, MIT or Apache-2.0. No copyleft obligations.
GPL-2.0 Open Babel, used through its Python bindings for docking preparation, is GPL-2.0. GPL obligations are triggered by distributing the software, not by running it on a server and offering access over a network. SmileBERTa is hosted, so users receive results, not binaries. If the Docker image or a desktop build were ever distributed, that calculus changes — and so would the options, such as moving Open Babel behind a process boundary.
LGPL-3.0 psycopg2, the PostgreSQL driver, is LGPL-3.0 and is used as an unmodified library.
Per-model Models pulled from Hugging Face through the Model Hub each carry their own licence. SmileBERTa does not redistribute them — it links to them, and generated notebooks download them directly from Hugging Face at runtime. Check a model's card before using it.

This section is a factual summary of the licences involved, compiled from each project's own metadata. It is not legal advice, and it is not a substitute for a lawyer if you intend to redistribute or commercialise this code.

Something missing or wrong?

If SmileBERTa uses your work and this page gets the citation wrong, or omits it, that is a bug and worth reporting. The list is maintained alongside the dependency files in the repository, so it should never drift from what the site actually runs.
